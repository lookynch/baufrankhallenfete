# Vorlagen für die App-Icons

Hier liegen die Originale, aus denen `node scripts/generate-icons.ts` alle Icons in `public/pwa/` erzeugt:

- `admin.png` – Adminbereich (Klemmbrett mit Zahnrad)
- `guest.png` – Gäste/Voting (Ticket)

Quadratisches PNG, mindestens 512 px. Ein eingebauter Rahmen mit runden Ecken wird automatisch abgeschnitten (14 % pro Seite), das Motiv sollte deshalb nicht bis an den Rand reichen.
